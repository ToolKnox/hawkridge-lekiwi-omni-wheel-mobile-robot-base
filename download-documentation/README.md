# Download the documentation

Everything for this build is in this GitHub repository.

1. On the repository front page, click **Code → Download ZIP**, or run `git clone https://github.com/ToolKnox/hawkridge-lekiwi-omni-wheel-mobile-robot-base.git`.
2. Start with the root `README.md`. It opens with the install and build guide.
3. Print files, source and the original upstream documentation are mirrored under `source/upstream/`.
